# Feuille de route après le rendez-vous

## Étape 1 — Comprendre le besoin

- identifier les utilisateurs ;
- identifier les décisions à faciliter ;
- préciser les zones et périodes prioritaires ;
- recenser les données disponibles.

## Étape 2 — Définir un pilote

Choisir avec les acteurs concernés :

- une zone ;
- un cas d’usage ;
- une période ;
- des critères de réussite.

## Étape 3 — Valider les données

Comparer les données satellitaires avec les informations disponibles localement.

## Étape 4 — Mesurer

Mesurer notamment :

- couverture ;
- délai ;
- faux positifs ;
- détections manquées ;
- qualité du regroupement ;
- utilité des alertes.

## Étape 5 — Améliorer

Adapter les paramètres, les données et les modèles aux observations réelles.

## Étape 6 — Expérimenter

Faire fonctionner la solution dans un cadre pilote contrôlé.

## Étape 7 — Évaluer la suite

Selon les résultats :

- poursuivre la recherche ;
- élargir le pilote ;
- renforcer l’infrastructure ;
- envisager un déploiement plus large.

> [!important] Principe
> **Ne pas commencer par le déploiement national. Commencer par un cas d’usage mesurable.**
