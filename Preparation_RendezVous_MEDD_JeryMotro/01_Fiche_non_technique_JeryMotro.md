# JeryMotro — Fiche non technique

## En une phrase

> **JeryMotro est un prototype de plateforme de surveillance et d’analyse des feux de végétation à Madagascar.**

## Le problème

La surveillance des feux demande de pouvoir :

- observer régulièrement un territoire très vaste ;
- localiser les détections ;
- regrouper les observations qui correspondent à un même événement ;
- suivre l’évolution d’un feu ;
- analyser son niveau de risque ;
- transmettre rapidement une information exploitable.

## La réponse proposée

JeryMotro cherche à transformer des données de détection satellitaire et des données complémentaires en informations utilisables :

**Observer → Regrouper → Analyser → Suivre → Alerter**

## Ce que l’on peut montrer

| Fonction | Explication simple |
|---|---|
| Carte | Voir les détections et événements sur une carte |
| Analyse | Exploiter plusieurs indicateurs pour caractériser le risque |
| Suivi | Suivre l’évolution d’un événement de feu |
| Statistiques | Consulter des indicateurs sur les détections/événements |
| Alertes | Configurer des notifications selon des conditions définies |
| Chat IA | Interroger les informations disponibles via une interface conversationnelle |

## Rôle de l’intelligence artificielle

L’IA n’est pas présentée comme une vérité absolue. Elle sert notamment à produire un **score d’analyse du risque** à partir de plusieurs variables.

> [!tip] Formulation à privilégier
> « L’intelligence artificielle est utilisée comme un outil d’aide à l’analyse et à la décision, en complément des données satellitaires. »

## Données

Le projet exploite notamment des données issues de **NASA FIRMS**, qui fournit des détections de feux actifs issues de capteurs satellitaires. D’autres données environnementales ou météorologiques peuvent compléter l’analyse selon les traitements disponibles.

## Intérêt potentiel pour le MEDD

JeryMotro pourrait constituer une base d’expérimentation pour :

- centraliser et visualiser des informations sur les feux ;
- faciliter le suivi d’événements ;
- tester des méthodes d’analyse assistées par IA ;
- expérimenter des mécanismes d’alerte ;
- confronter les données satellitaires aux observations et besoins institutionnels.

## Ce que JeryMotro ne prétend pas faire

- remplacer les agents de terrain ;
- confirmer avec certitude qu’un feu est éteint à partir d’une simple absence de détection ;
- garantir une prédiction parfaite ;
- remplacer les procédures institutionnelles de décision.

## Niveau actuel

> [!warning] Prototype
> Le projet comporte plusieurs briques fonctionnelles, mais certaines fonctions et intégrations nécessitent encore une validation plus poussée sur des données et conditions réelles.

La prochaine étape logique est donc une **validation avec les besoins, données et observations du terrain**, éventuellement dans une zone pilote.

## Message final

> **L’objectif est de transformer des données environnementales complexes en informations plus faciles à observer, analyser et exploiter pour la surveillance des feux.**
